# Snowflake Data Applications Builders Workshop (badge 3)

## Important: Suspend `SYSTEM_COMPUTE_POOL_CPU` once done to avoid compute cost 
```sql
SHOW COMPUTE POOLS;
SHOW SERVICES IN COMPUTE POOL SYSTEM_COMPUTE_POOL_CPU;
USE ROLE ACCOUNTADMIN;

ALTER COMPUTE POOL SYSTEM_COMPUTE_POOL_CPU
SET AUTO_RESUME = FALSE;

ALTER COMPUTE POOL SYSTEM_COMPUTE_POOL_CPU RESUME;
ALTER COMPUTE POOL SYSTEM_COMPUTE_POOL_CPU SUSPEND;
```
